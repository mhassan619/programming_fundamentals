# 🚀 Programming Fundamentals From Syntax to Problem Solver

> **The goal isn't to learn another programming language.**
> **The goal is to learn how to think like a programmer.**

Welcome to my **Programming Fundamentals** journey. 👋

I've already studied Programming Fundamentals in **C++, Python, and JavaScript**, so this isn't a "hello world → variables → loops" course from scratch.

This time, the goal is different:

### 🧠 Understand → Practice → Debug → Think → Solve

I'm rebuilding my fundamentals with a **DSA-oriented mindset**, so that when I face a difficult DSA problem, the difficulty comes from the **problem itself — not from weak programming fundamentals.**

---

## 🎯 The Mission

By the end of this roadmap, I want to be able to:

* Break a problem into smaller parts
* Convert logic into clean code
* Understand what happens behind the code
* Debug my own mistakes
* Choose the right programming construct
* Reason about memory and execution
* Analyze time and space complexity
* Recognize common problem-solving patterns
* Approach DSA problems with confidence

> **Syntax is easy to memorize.**
> **Logic is what we're here to build.**

# 🔥 What We'll Actually Learn

## 🧠 01 — Computational Thinking

Before writing code, learn how to **think about the problem**.

We'll focus on:

* Problem decomposition
* Inputs & outputs
* Constraints
* Step-by-step reasoning
* Algorithms vs code
* Pseudocode
* Edge cases

> **Don't code immediately. Think first.**

---

## 📦 02 — Variables & Data Types

Understanding what data actually looks like in memory.

We'll cover:

* Variables
* Primitive data types
* Type conversion
* Constants
* Initialization
* Signed vs unsigned concepts
* Integer & floating-point behavior

---

## ⚙️ 03 — Operators

Not just memorizing operators — understanding how expressions are evaluated.

* Arithmetic
* Relational
* Logical
* Assignment
* Increment / decrement
* Modulus
* Operator precedence

---

## 🔀 04 — Conditions

Teach the program to **make decisions**.

```cpp
if
else if
else
switch
```

And more importantly:

> **How do I turn a real-world decision into logic?**

---

## 🔁 05 — Loops

Make the computer repeat work without repeating code.

* `for`
* `while`
* `do-while`
* Counters
* Accumulators
* Loop conditions
* Infinite loops
* Nested iteration

---

## 🌀 06 — Nested Loops & Patterns

Time to make the brain work a little harder. 😈

We'll explore:

```text
*
**
***
****
```

and more complex patterns.

But the real goal is understanding:

* Row/column thinking
* Nested iteration
* Loop dependencies
* Pattern decomposition

---

## 🧩 07 — Functions

Move from writing code to **designing reusable logic**.

* Parameters
* Arguments
* Return values
* Function prototypes
* Pass by value
* Pass by reference
* Function decomposition
* Local vs global behavior

---

## 🔒 08 — Scope & Lifetime

Understand **where variables exist and how long they exist**.

We'll explore:

* Local scope
* Global scope
* Block scope
* Lifetime
* Stack frames
* Function execution

This becomes especially important when we reach recursion and memory.

---

## 📚 09 — Arrays

The beginning of serious data handling.

* Array declaration
* Indexing
* Traversal
* Searching
* Updating
* Passing arrays to functions
* Array + recursion
* Common mistakes

---

## 🔤 10 — Strings

Working with text as data.

* Character access
* String traversal
* String manipulation
* Searching
* Comparison
* String + recursion
* Palindrome problems

---

# 🧠 11 — Pointers

Now things get interesting. 👀

We'll understand:

```cpp
int *ptr;
```

instead of simply memorizing it.

Topics:

* Addresses
* Dereferencing
* Pointer arithmetic
* Pointers & arrays
* Pointers & functions
* Pointer behavior in memory

> **If pointers scare you, that's exactly why we're learning them properly.**

---

# 🔗 12 — References

Understanding another way of working with existing data.

```cpp
int &ref = x;
```

We'll connect references with:

* Functions
* Arrays
* Pointers
* Pass-by-reference
* Efficient data manipulation

---

# 🧠 13 — Memory: Stack & Heap

One of the most important foundations for DSA and C++.

We'll understand:

```text
Program
│
├── Stack
│
└── Heap
```

Including:

* Stack frames
* Local variables
* Function calls
* Memory allocation
* Object lifetime
* Why stack overflow happens

---

# 💾 14 — Dynamic Memory

Understanding memory that is created during runtime.

We'll explore:

* Dynamic allocation
* `new`
* `delete`
* Dynamic arrays
* Memory management
* Common memory mistakes

---

# 🏗️ 15 — Structs

Learn how to create custom data structures before moving deeper into DSA.

```cpp
struct Student {
    string name;
    int age;
};
```

We'll learn:

* Structure declaration
* Members
* Objects
* Arrays of structs
* Structs with functions

---

# 🧱 16 — OOP Fundamentals

A strong foundation before larger software and DSA implementations.

We'll cover:

* Classes & objects
* Constructors
* Encapsulation
* Access modifiers
* Inheritance basics
* Polymorphism basics
* Abstraction basics

---

# 🧰 17 — STL Fundamentals

C++'s toolbox for solving problems efficiently.

We'll build familiarity with:

```text
vector
string
pair
stack
queue
set
map
```

and understand **when and why** to use them.

# 🐛 18 — Error Handling & Debugging

Because writing code is only half the job.

The other half:

> **Finding out why your code doesn't work.**

We'll learn to deal with:

* Compile-time errors
* Runtime errors
* Logical errors
* Debugging strategies
* Reading error messages
* Tracing program execution
* Finding bugs systematically

---

# ⏱️ 19 — Time & Space Complexity

Before going deep into DSA, we need to understand:

> **How expensive is my solution?**

We'll build intuition for:

```text
O(1)
O(log n)
O(n)
O(n log n)
O(n²)
O(2ⁿ)
```

And learn to analyze:

* Time complexity
* Space complexity
* Recursion depth
* Number of operations

# 🔄 21 — Recursion

The final major recursion milestone.

We'll build a complete mental model of:

* Base cases
* Recursive cases
* Smaller problems
* Call stack
* Unwinding
* Linear recursion
* Tree recursion
* Multiple parameters
* Return-value recursion
* Index recursion
* Two-pointer recursion
* Divide & conquer
* Recursion complexity
* Backtracking

### Example patterns:

```text
Linear Recursion
       ↓
Index Recursion
       ↓
Two-Pointer Recursion
       ↓
Tree Recursion
       ↓
Divide & Conquer
       ↓
Backtracking
```

> **Recursion isn't about making a function call itself.**
> **It's about reducing a problem into a smaller version of itself.**
